# chuaykan-mini-call-bordcast-
# แอพพลิเคชั่น ช่วยกัน (มินิ คอลบอร์ดเคส) สำหรับประเทศไทย
แอพนี้พัฒนามาเพื่อช่วยเหลือพี่น้องชาวไทย โดยไม่แสวงหาผลกำไร และต้องการช่วยเหลือด้วยใจจริง
- แอพนี้ทำมาเพื่อใคร? ทำมาเพื่อพี่น้องชาวไทยที่มีมือถือรุ่นเก่า และไม่สามารถรับการแจ้งเตือนจากภาครัฐได้ถ่วงที หมดเวลาที่ต้องรอคอยช่วยเหลือต่อไป และเตรียมพร้อมในการรับมือภัยพิบัติล่วงหน้า ไปพร้อมกับมือถือรุ่นใหม่ และฟีเจอร์ต่างๆในการรองรับภัยพิบัต 3 ช่วง ได้แก่ ก่อนเกิดเหตุ ช่วงเกิดเหตุ และหลังเกิดเหตุ

เป้าหมายหลักของโครงการ:

- รวมข่าวสารภัยพิบัติและแผนที่ให้พี่น้องชาวไทยติดตามสถานการณ์ได้
- ให้เจ้าหน้าที่กำหนดพื้นที่คุมและส่งประกาศถึงผู้ใช้งานที่ตรงกับพื้นที่
- แยกเคสผู้ป่วยฉุกเฉินออกจากคำขอความช่วยเหลือทั่วไป เพื่อให้เจ้าหน้าที่จัดการได้ชัดเจน
- ให้เจ้าหน้าที่เห็นพิกัด ตรวจรายละเอียด และติดต่อกลับผู้ส่งเคส
- เก็บโปรไฟล์ส่วนตัวไว้ในมือถือ และส่งรายละเอียดพร้อมเคสเมื่อผู้ใช้กดขอความช่วยเหลือเอง

ฟีเจอร์ต่างๆที่มีในแอพพลิเคชั่น มีดังนี้
- Call Bordcast สำหรับแจ้งเตือนภัยพิบัติล่วงหน้าจาก ปภ.
- วิทยุ คลื่น AM และ FM ในการฟังข่าวสารและการเตือนภัย จาก สวท และ กสทช
- Bluetooth Mesh การติดต่อ โทรผ่านบลูทูธที่ไม่ใช้อินเตอร์เน็ต โดยเชื่อมต่อระหว่างกันเป็นทอดๆ เพื่อสร้างโครงข่ายสื่อสาร เพื่อสื่อสารระหว่างกันได้ช่วงระหว่างภัยพิบัติ
- แผนที่ สามารถดูแผนที่เพื่อหาศูนย์อพยพ หรือพื้นที่ปลอดภัย และที่จอดรถได้แบบเรียลไทม์
- คู่มือการเอาตัวรอดจากภัยพิบัติ และการรับมือ 3 ช่วง
- ข่าวสารและเตือนภัย สามารถเช็คข่าวแบบเรียลไทม์ผ่าน ปภ. และ กรมอุตุนิยมวิทยา
- เบอร์ฉุกเฉินและหน่วยงานกู้ภัย เช็คเบอร์ฉุกเฉินและโทร ได้แบบเร่งด่วนทุกสถานการณ์
- เช็คเขื่อนและระดับน้ำ สามารถตรวจเช็คระดับน้ำจาก ไทยวอเตอร์และกรมชลประทานแบบเรียลไทม์ เพื่อรับมือล่วงหน้าจากเหตุการณ์น้ำท่วมได้

แอพพลิเคชั่นนี้ไม่แสวงหาผลกำไรเชิงพาณิชย์ทุกชนิด ปราศจากไวรัสและมัลแวร์ และการดักจับข้อมูล
แอพลิเคชั่นนี้ ไม่ส่งข้อมูลส่วนบุคคลเข้าเซิฟเวอร์เพื่อบันทึกข้อมูลส่วนบุคคล สารมารถตรวจสอบได้
การช่วยเหลือเสร็จสิ้นจะไม่บันทึกข้อมูลส่วนบุคคล และจะลบข้อมูลออกทั้งหมด โดยจะนับเป็นจำนวนช่วยเหลือแทน
หากต้องการตรวจสอบแอพ สามารถดาวน์โหลดไฟล์ TXT และ ZIP ในแอพเพื่อตรวจสอบข้อมูลและข้อกฏหมาย เพื่อตรวจสอบความโปรงใสได้

# สำหรับผู้ที่ต้องการนำไปพัฒนาต่อ

# กฏข้อห้ามก่อนนำไปพัฒนา
- ผู้พัฒนาต้นฉบับจะไม่รับผิดชอบใดๆทั้งสิ้น เมื่อนำไปพัฒนา ดัดแปลง แก้ไขใหม่ ที่ไม่ใช่ผู้พัฒนาต้นฉบับโดยตรง
- การดัดแปลง แก้ไข หากมีปัญหาเกี่ยวกับไวรัส มัลแวร์ ฟิชชิ่ง โทรจัน และการดักจับข้อมูล ผู้พัฒนาต้นฉบับจะไม่รับผิดชอบใดๆทั้งสิ้น ถือว่าเป็นเรื่องที่นอกเหนือจากผู้พัฒนาโดยตรงที่ได้ทำไว้ และต้องรับผิดชอบตามกฏหมายเพียงผู้เดียว
- ไม่อนุญาติให้แสวงหาผลกำไร เชิงพาณิช ใดๆทั้งสิ้น หากพบเจอหรือมีการแจ้งข้อมูลเข้ามา จะดำเนินคดีตามกฏหมายให้ถึงที่สุด ถือว่าทำผิดกฏตามที่ผู้พัฒนาต้นฉบับได้ตั้งไว้
- ขอให้ผู้ที่นำไปพัฒนาต่อ ทำด้วยใจสัตย์จริง และเคารพตามกฏหมาย และจดจำขึ้นใจอยู่ตลอดเวลา

# เมื่ออ่านกฏครบแล้ว สามารถนำไฟล์ zip open source ไปพัฒนาต่อได้เลย

## การใช้งานบนมือถือ Android

### 1. ติดตั้งและเตรียมเครื่อง

1. ติดตั้งไฟล์ `Chuaykan-2.4.27-release.apk` บนอุปกรณ์ Android 5.0 ขึ้นไป
2. เปิดแอพ อ่านข้อตกลงและข้อมูลส่วนบุคคลจากเมนูของแอพ
3. ให้สิทธิ์ตามการใช้งานที่แอพร้องขอ เช่น ตำแหน่ง การแจ้งเตือน กล้อง ไมโครโฟน และ Bluetooth
4. กรอกข้อมูลติดต่อและข้อมูลที่จำเป็นต่อการช่วยเหลือ ตรวจว่าข้อมูลถูกต้องและเป็นปัจจุบัน
5. เปิดอินเทอร์เน็ตและตำแหน่ง เพื่อให้ระบบตรวจพื้นที่และใช้พิกัดจริงในการส่งเคส

APK ที่จัดไว้ยังใช้การเชื่อมต่อเกตเวย์ของระบบเดิม ส่วนผู้ที่นำซอร์สไปบิลด์เองต้องตั้งค่าเซิร์ฟเวอร์และบริการของตนเองก่อน

### 2. ติดตามข่าวสารและแผนที่

- เปิดเมนูข่าวสารเพื่อติดตามข้อมูลภัยพิบัติ ตรวจวันที่และแหล่งที่มาของแต่ละรายการ
- เปิดแผนที่เพื่อดูข้อมูลข่าว พื้นที่คุม และตำแหน่งศูนย์อพยพที่ระบบได้รับ
- ข่าวบนแผนที่และประกาศจากเจ้าหน้าที่มีวัตถุประสงค์ต่างกัน ให้ตรวจชนิดและเวลาของข้อมูลก่อนใช้งาน
- หมุดพื้นที่คุมและศูนย์อพยพปรับตามข้อมูลจากเจ้าหน้าที่เมื่อการเชื่อมต่อทำงาน หากเครื่องขาดการเชื่อมต่ออาจยังเห็นข้อมูลเดิม

### 3. รับประกาศจากเจ้าหน้าที่

เปิดสิทธิ์การแจ้งเตือนและตำแหน่งตามที่แอพร้องขอ เมื่อระบบได้รับประกาศที่ตรงตามเงื่อนไขพื้นที่ แอพจะแสดงการแจ้งเตือนและประกาศตามรูปแบบที่อุปกรณ์อนุญาต


### 4. ส่งเคสผู้ป่วยฉุกเฉิน

1. เมื่อปุ่ม **ผู้ป่วยฉุกเฉิน / SOS** พร้อมใช้งาน ให้กดเพื่อเข้าสู่ขั้นตอนส่งเคส
2. ถ่ายภาพตามขั้นตอนของแอพ ตรวจข้อมูลและพิกัด ก่อนยืนยันส่ง
3. ตรวจสถานะการส่งที่แอพแสดง และรอเจ้าหน้าที่รับเคสหรือประสานงาน

บนแผนที่เจ้าหน้าที่ เคสผู้ป่วยฉุกเฉินใช้หมุดสีแดงพร้อมคำว่า **SOS** การส่งเคสเป็นการส่งข้อมูลให้เจ้าหน้าที่ เจ้าหน้าที่เป็นผู้เลือกติดต่อกลับเพื่อประสานงาน

### 5. ส่งคำขอความช่วยเหลือทั่วไป

1. กดปุ่ม **ต้องการช่วยเหลือ**
2. ตรวจข้อมูลติดต่อ พิกัด และข้อมูลคำขอ แล้วกดยืนยัน
3. ตรวจสถานะการส่ง และรอเจ้าหน้าที่ประสานงานต่อ

คำขอนี้เข้าคิวช่วยเหลือทั่วไป และใช้หมุดสีน้ำเงินบนแผนที่เจ้าหน้าที่ การส่งต้องมี GPS ที่ระบบยืนยันว่าอยู่ในพื้นที่แจ้งเตือนตามเงื่อนไขของแอพ

หากปุ่มไม่พร้อมใช้งาน ให้ตรวจสถานะคำขอเดิม ตำแหน่ง และพื้นที่แจ้งเตือนก่อน หลังได้รับการช่วยเหลือ ระบบซ่อนหรือล็อกปุ่ม SOS เพื่อป้องกันการส่งซ้ำเป็นเวลา **72 ชั่วโมง (3 วัน)** แล้วจึงปลดตามเงื่อนไขของระบบ

### 6. การติดต่อกลับ

เมื่อเจ้าหน้าที่เลือกโทรกลับเคส ให้รับสายตามหน้าจอของแอพ และอนุญาตไมโครโฟนเพื่อสนทนา การสนทนาผ่านอินเทอร์เน็ตต้องมีการเชื่อมต่อทั้งฝั่งมือถือ เจ้าหน้าที่ และเกตเวย์ ส่วน Bluetooth ต้องใช้อุปกรณ์และการเชื่อมต่อที่รองรับ



## การใช้งานบนคอมพิวเตอร์สำหรับเจ้าหน้าที่

### 1. เปิดโปรแกรม Windows

1. แตกไฟล์ `Chuaykan-EOC-2.4.27-Windows-x64.zip` ทั้งโฟลเดอร์
2. เปิด `Chuaykan.exe` โดยเก็บโฟลเดอร์ `_internal` ไว้คู่กัน
3. อ่านข้อตกลงก่อนเข้าใช้งาน
4. ให้ผู้ดูแลตั้งค่าเกตเวย์ Oracle และ credentials ส่วนตัวตาม `README.md` ที่แนบในชุด Windows
5. ตรวจการเชื่อมต่อ การรับเคส ตำแหน่ง ไมโครโฟน และลำโพงก่อนเริ่มใช้งาน

หากกราฟิกมีปัญหา สามารถทดลองเปิดด้วย `Run-Software-Rendering.cmd` ที่แนบไว้ได้ ชุด Windows ไม่มี credentials ของเจ้าหน้าที่ติดมา จึงต้องตั้งค่าก่อนรับ–ส่งกับเกตเวย์จริง

### 2. รับและจัดการเคส

- เปิดเมนูคิวแจ้งเหตุเพื่อดูเคสผู้ป่วยฉุกเฉินและคำขอช่วยเหลือทั่วไป
- เลือกเคสเพื่อตรวจรายละเอียดและพิกัดบนแผนที่
- ใช้การติดต่อกลับเมื่อจำเป็น และประสานงานกับเจ้าหน้าที่ที่เกี่ยวข้อง
- เมื่อช่วยเหลือเสร็จ ให้กดสถานะช่วยเหลือแล้ว ระบบลบรายละเอียดเคสตามขั้นตอนและเก็บจำนวนที่ช่วยเหลือแล้วไว้ในแคช จำนวนนี้หายไปเมื่อเจ้าหน้าที่ล้างแคช

### 3. คุมพื้นที่และประกาศ

- ใช้เมนูคุมพื้นที่กำหนดบริเวณที่เจ้าหน้าที่ดูแล
- ใช้เมนูไมค์ประกาศเพื่อส่งเสียงประกาศตามเงื่อนไขพื้นที่และการเชื่อมต่อของระบบ
- หมุดไมค์ประกาศและหมุดคุมพื้นที่แยกกัน การล้างหมุดไมค์ใช้สำหรับหมุดไมค์ ส่วนการถอนพื้นที่คุมต้องจัดการในเมนูคุมพื้นที่
- การปิดความเสี่ยงใช้ถอนตำแหน่งที่ปักไว้ โดยไม่มีประกาศแจ้งเตือนใหม่จากการปิดนั้น

### 4. Bluetooth และการโทร

เปิด Bluetooth ตรวจอุปกรณ์และการเชื่อมต่อก่อนใช้ เจ้าหน้าที่จัดการผู้ติดต่อและคิวรอสายในเมนู Bluetooth ได้ และระงับผู้ติดต่อที่เลือกจนกว่าจะเปิดให้ติดต่ออีกครั้ง

Windows ใช้ตัวเชื่อม Bluetooth และเสียงที่เพิ่มสำหรับระบบนี้ ต้องมีอะแดปเตอร์และไดรเวอร์ที่รองรับ จึงยังต้องตรวจการรับ–ส่งและเสียงกับมือถือจริงก่อนนำไปใช้
